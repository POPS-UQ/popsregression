% Medians and central 90% intervals over 30 independent training draws (fixed test sets). Every interval is an exact central interval of the method's parameter-only predictive (no residual-noise term). IS: interval score (Gneiting and Raftery) of the 95.45% interval, lower is better. NLL: negative log predictive density, floored as -log((1 - b) p + b / R_y) with b = 0.01 on the declared output interval of width R_y (a comparison score; the PAC certificate uses its own beta = 0.02). A_abs = int |C(u) - u| du and A_s = int (C(u) - u) du for the pooled absolute-error P-P curve C (smaller A_abs is better; A_s > 0 means net over-confidence, but A_s = 0 does not imply agreement). The PIT areas use u_i = F_i(y_i) instead and measure input-conditional calibration. Burgers test points are weighted so every simulator case counts equally in the areas. The POPS hypercube has no density (no NLL, no PIT from a density: its PIT uses its draws). '*' marks cells where at least one fit did not report optimizer convergence; those iterates are kept, not dropped. Abbreviations: POPS = pointwise optimal parameter sets; EB = empirical Bayes; PAC = probably approximately correct (PAC-Bayes hyperparameter bound); PACm = PAC-Bayes objective with an m-sample predictive (Morningstar et al. 2022); PAC$^2_T$ = second-order PAC-Bayes objective with the tandem Taylor weight (Masegosa 2020); PVI = predictive variational inference (Lai, Linero and Yao); IS = interval score (Gneiting and Raftery), of the 95.45% central interval; NLL = negative log predictive density.
